📖 General guide

Step 1: Turn on automatic backup

Do this first. Open the guide “Automatic backup with Google Drive” below. You do it only once. After that, the app saves a backup file a few seconds after every Save.

Not on Windows with Chrome or Edge? Press “Backup (JSON)” now and then, and keep the file in Google Drive or another safe place.

Your files

  • JSON file (Backup): everything is inside. “Full restore” uses it to bring your words back. It replaces all words in the app with the words in the file.
  • Anki file (Export for Anki): for review cards. See the Anki guide below.

Add a word

  1. Fill in the three top boxes: Book title (no spaces, for example Athenaze), Chapter number, and Page number (digits only). They stay until you change them.
  2. Word class: press its number, 1 to 9.
  3. Word: type the word. A red message appears if you saved it before.
  4. Declension / conjugation: the Greek tables are still being designed. For now this panel has only a note box.
  5. Essential information: write it like the examples above the box.
  6. Meanings: write the English and the Persian meaning. Press “Add more meanings” for more. English meaning 1 matches Persian meaning 1.
  7. Press Save.

Find words

Use the filters: Book title, Chapter number, Page number, Word class, and Inflection status. In “Sort by”, choose “Least inflected first” to see the words you practiced least.

Do not worry. With automatic backup on, your words are safe. If something goes wrong, press “Full restore”.

☁️ Automatic backup with Google Drive

This works only on Windows with Chrome or Edge.

  1. Install Google Drive for desktop and sign in. Skip this if it is already installed.
  2. Open File Explorer. On the left, open Google Drive, then My Drive.
  3. Make a new folder named Greek-Backup.
  4. Come back to this app and press “Choose backup folder”.
  5. Choose Google Drive, then My Drive, then Greek-Backup. Press Select Folder.
  6. The browser asks for permission. Press Allow or Edit files.
  7. Press “Backup (JSON)”. You should see “Backup saved ✓” and “✅ Automatic backup is on”.
  8. Open the Greek-Backup folder. You should see a file named greek-vocab-latest.json. A green check mark appears when it is online.

After that it is automatic. A few seconds after every Save, the app writes two files: greek-vocab-latest.json (always the newest) and one file for each day (it keeps the last 7 days).

If a red bar asks for permission, press “Allow”.

If a red bar says the number of words is much smaller than in the last backup, your words may be lost. The app does not replace the old file. Press “Full restore” and choose greek-vocab-latest.json.

If it says “Backup saved to the Downloads folder”, the folder was not chosen or permission was not given. Do steps 4 to 6 again.

OneDrive and Dropbox folders work the same way.

🃏 Anki cards

Anki is a free app for reviewing cards. It shows each card just before you would forget it.

You need Anki only if you want to review your words on your phone or on Windows. If you only add words, skip this guide.

Why use it?

  • It shows hard cards more often and easy cards less often.
  • A few minutes a day is enough.
  • It works on your phone and on Windows, and your cards stay in sync.
  • Every word gets two cards: Greek → meaning and meaning → Greek.
  • Book, chapter and page become tags, so you can review one chapter only.

Step 0: Install

  1. Install Anki on Windows (free).
  2. Install AnkiDroid on Android from Google Play (free).
  3. Make a free account at ankiweb.net. It keeps your cards in sync.

Step 1: Make the note type (once)

These steps are for AnkiDroid. Windows is similar; the differences are in brackets.

  1. Tap ⋮ and choose Manage note types. (Windows: Tools → Manage Note Types.)
  2. Tap Add and choose Add: Basic.
  3. Type the name LinguaGraeca and tap OK.
  4. Tap LinguaGraeca to open Manage fields. (Windows: select LinguaGraeca, then Fields.)
  5. Rename Front to Word. Rename Back to DictForm.
  6. Add five more fields. Tap Add, type the name, and confirm. The order must be: Type, Meaning, Example, Notes, Conjugation. It saves by itself. (Windows: press Save at the end.)
  7. The final order is: Word, DictForm, Type, Meaning, Example, Notes, Conjugation.

Step 2: Make two cards (once)

Go back to the note types list. Next to LinguaGraeca you see two icons: ⋮ and an icon with three lines and a pencil. Tap the three-lines-and-pencil icon to open the card templates. (Windows: select LinguaGraeca, then Cards.)

For the first card: from the ⋮ menu choose Rename Card Type and name it Greek to Meaning. Then copy and paste these three texts.

Front Template:

<div class="lat big">{{Word}}</div>
<div class="lat small">{{DictForm}}</div>

Back Template:

{{FrontSide}}
<hr id=answer>
<div class="meaning">{{Meaning}}</div>
{{#Example}}<div class="lat ex">{{Example}}</div>{{/Example}}
{{#Notes}}<div class="notes">{{Notes}}</div>{{/Notes}}
{{hint:Conjugation}}

To hide the word class on the second card, delete the line {{Type}}. Then save.

The conjugation table is not shown on the card. Tap the “Show Conjugation” link on the back of a card to see it.

Step 3: Move your words to Anki

Each time you want to move words to Anki, first press “Export for Anki” in this app. Then import that file in Anki (Android or Windows).

  1. Press “Export for Anki”. A .txt file is downloaded.
  2. In Anki find Import (Windows: File menu. Android: ⋮ menu) and choose the file.
  3. Check that the note type is LinguaGraeca and the deck is Ancient Greek. Press Import.
  4. If Anki asks about “Existing notes”, choose Update.

Next time, add new words, export again and import again. Old words are updated, and no duplicate cards are made.

Step 4: Phone

Press Sync in Anki on your computer. Then press Sync in AnkiDroid. Your cards appear on the phone.

If you change a card on the phone, it changes only in Anki. If you see a mistake, fix it in this app and export again.
